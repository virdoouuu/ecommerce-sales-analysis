# Raw data

Source: Online Retail II, UCI Machine Learning Repository.
Page: https://archive.ics.uci.edu/dataset/502/online+retail+ii

How to get it:
1. Download the dataset from the page above.
2. Unzip and place `online_retail_II.xlsx` in this folder.

Raw files are never edited. All cleaning is done in code and saved to `data/processed/`.
